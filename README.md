# brazil-congenital-anomalies
Epidemiological analysis of congenital anomalies in Brazil using SINASC data.
Project Status: in progress.

The purpose of this project is to describe the epidemiological profile of congenital anomalies in Brazil using data available in SINASC (Information System on Live Births). 

Objectives:
- Describe the frequency of congenital anomalies;
- Explore regional distribution of congenital anomalies;
- Investigate differences in the distribution of congenital anomalies;
- Discuss data quality, underreporting and limitations of SINASC.

Tools used:
- RStudio.
