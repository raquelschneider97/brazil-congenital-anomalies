# brazil-congenital-anomalies
Epidemiological analysis of congenital anomalies in Brazil using SINASC data.
Project Status: in progress.

The purpose of this project is to describe the epidemiological profile of congenital anomalies in Brazil using data available in SINASC (Brazilian Live Birth Information System). 

Objectives:
- Describe the frequency of registered congenital anomalies among live births.
- Explore the regional distribution of congenital anomalies in Brazil.
- Investigate differences according to maternal and newborn characteristics.
- Discuss data quality, underreporting, and limitations of SINASC.

Tools used:
- R
- RStudio
- Git
- GitHub
